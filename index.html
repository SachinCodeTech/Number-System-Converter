How to Use

  1. Press On to enable input. Tap again for Off (input disabled).
  2. Select a conversion type from the dropdown.
  3. Use the keypad to enter your number (only valid keys are allowed).
  4. Press Convert to see the result, or Step-by-Step for logic.
  5. Copy the output or review your conversion history.
  6. Switch between Light/Dark mode using the bottom nav bar.
  7. Long-press C to clear all input, tap for backspace.

What is This?

This tool converts numbers between Binary, Decimal, Octal, Hexadecimal, and Roman numerals. For each conversion, you'll see not only the answer but also the steps taken to get there.

Supported Conversions

  • Binary, Octal, Decimal, Hexadecimal, and Roman numerals (1-3999)
  • All standard conversions between these systems
